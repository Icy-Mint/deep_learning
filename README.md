# Deep Learning Projects

A collection of deep learning experiments covering convolutional networks, transformer language models, and diffusion-based image generation. Each project is self-contained in its own directory with its own notebook, code, and results.

## Projects

### [fashionmnist-regularization-study](fashionmnist-regularization-study/)
Comparing four regularization strategies — baseline, dropout, weight decay, and batch normalization — on a LeNet-5 CNN trained to classify FashionMNIST images.

### [ptb-transformer-language-model](ptb-transformer-language-model/)
A causal Transformer language model trained on the Penn Treebank (PTB) corpus, with a hyperparameter sweep over attention heads and layer depth, evaluated by perplexity.

### [diffusion-model-exploration](diffusion-model-exploration/)
Hands-on exploration of diffusion models: visualizing the forward noising process, comparing DDIM sampling at different step counts, and using Stable Diffusion for text-guided image-to-image editing.

## Stack

PyTorch, torchvision, torchtext, Hugging Face `diffusers`, matplotlib, pandas.
